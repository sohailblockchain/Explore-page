A practical teaching resource that helps data-science students build a credible professional profile, present portfolio projects clearly, and develop a focused final-project proposal.

## What students learn

- Write a targeted LinkedIn headline and professional About section.
- Select relevant data-science skills and support them with evidence.
- Document GitHub and Kaggle projects professionally.
- Explain a project through its problem, data, method, metric, and result.
- Select an achievable final-project idea and dataset.
- Define scope, risks, success criteria, and deliverables.

## Run locally

No build tools or dependencies are required.

```bash
git clone https://github.com/sohailblockchain/data-science-career-project-workshop.git
cd data-science-career-project-workshop
```

Open `index.html` in any modern browser, or start a small local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
